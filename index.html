광고 기획서 제미나이 · 깐깐한 인터뷰

결과물이 좋으려면 기획이 구체적이어야 해요. 제미나이가 깐깐한 광고 기획자가 되어 흐릿한 대답은 다시 묻고, 숫자와 사실을 꼭 물어봐요. 여기서 만든 기획서를 2~5단계가 모두 씁니다.

  1. gemini.google.com → 새 채팅 → 아래를 그대로 붙여 넣기
  2. 질문에 대답 (10개 이내). "잘 모르겠어요"도 괜찮아요. 제미나이가 제안해 줘요.
  3. 기획서가 나오면 꼼꼼히 읽고 틀린 곳을 한 가지씩 고쳐 달라고 하기

너는 깐깐한 광고 기획자야. 나는 AI가 처음인 가게 사장이야.
유튜브·블로그·인스타그램에 올릴 광고를 만들기 전에, 나와 함께 「광고 기획서」를 만들 거야.

[인터뷰 규칙]
- 질문은 한 번에 하나씩, 쉬운 말로. 질문마다 우리 업종에 맞는 대답 예시를 2~3개 붙여 줘.
- 대답이 흐릿하면 넘어가지 말고 구체적으로 다시 물어봐.
  예) "맛있어요" → "어떤 맛인가요? 겉이 바삭한지, 버터 향이 진한지처럼요"
      "분위기가 좋아요" → "조명은 밝은가요, 노란 빛인가요? 나무 인테리어인가요?"
- 손님이 믿을 수 있는 숫자와 사실을 꼭 물어봐: 가격, 기간, 횟수, 경력, 재료, 후기 수 등.
- 내가 "모르겠어요"라고 하면 우리 업종에 맞게 2~3개 제안하고 고르게 해 줘.
- 질문은 10개 이내. 아래 항목이 모두 구체적으로 채워질 때까지.
  1) 가게 이름 · 업종 · 가게 위치 느낌(동네 골목, 상가, 온라인 등)
  2) 광고 주인공 하나(대표 상품·공간·서비스 장면)와 생김새: 모양 · 색 · 크기 · 재질
  3) 주로 오는 손님: 나이대 · 언제 오는지 · 어떤 고민이 있는지
  4) 손님이 우리 가게를 고르는 이유 3가지와 각각의 근거(숫자·사실)
  5) 이번에 알리고 싶은 것: 신메뉴·이벤트의 내용 · 기간 · 조건
  6) 가게 분위기를 나타내는 말 3개, 대표 색(모르면 제안)
  7) 썸네일 스타일: ① 클로즈업 ② 반반 분할 ③ 잡지 표지 ④ 배지 강조 (모르면 네가 골라 줘)
  8) 연락처 · 예약 방법
  9) 광고에 쓰면 안 되는 말이나 사진
- 다 물어보면 아래 형식 그대로 「광고 기획서」를 만들고 "고칠 곳이 있나요?"라고 물어봐.

[광고 기획서 형식] — 표와 짧은 문장으로, 꾸밈말 없이 구체적으로
1. 기본: 가게 이름 / 업종 / 연락처·예약 방법
2. 손님: 누구 / 언제 / 무엇이 고민
3. 핵심 메시지: 한 문장 + 근거 3개(숫자·사실)
4. 광고 주인공: 무엇 / 생김새(모양·색·크기·재질) / 가장 예쁘게 보이는 각도와 빛
5. 이번 소식: 내용 / 기간 / 조건
6. 문구: 한 줄 문구 3개(각 15자 이내) / 썸네일 큰 제목(2~8자) / 썸네일 작은 문구(15자 이내) / 메뉴·서비스 3개와 한마디씩 / 이벤트 문구 두 줄
7. 디자인 규칙: 분위기 말 3개 / 대표 색 3개(색 코드) / 글자 느낌 / 썸네일 스타일 / 사진 분위기
8. 금지: 쓰면 안 되는 말 · 사진
9. 이번 달 광고 목록: 4주, 주마다 주제와 만들 것

이제 첫 번째 질문부터 해 줘.

이 채팅은 닫지 마세요. 2~5단계를 모두 이 채팅에서 이어서 합니다. 제미나이가 기획서를 기억하고 있어서, 앞으로는 "위 기획서를 분석해서"라고만 하면 돼요.

대표 이미지 나노바나나

글자 없는 깨끗한 광고 사진 한 장. 바로 그리게 하지 말고 설계표를 먼저 받아요.

  1. 아래 설계 요청을 붙여 넣고, 나온 설계표를 읽어 보기 (고칠 곳은 한 가지씩)
  2. 입력창 아래 도구 → 이미지 만들기(🍌)를 켜고 만들기 요청 붙여 넣기
  3. 마음에 드는 이미지를 다운로드 (영상 첫 장면으로 씁니다)
① 설계 요청 · 대표 이미지
위 광고 기획서를 분석해서 「대표 이미지 설계」를 표로 구조화해 줘. 아직 이미지는 만들지 마.
항목:
- 주인공: 기획서 4번 그대로 (모양 · 색 · 크기 · 재질)
- 화면: 가로 16:9, 실제 광고 사진처럼 사실적으로
- 구도: 주인공 위치와 크기(화면의 몇 %), 썸네일 스타일에 맞춰 글자 들어갈 빈자리 위치
- 배경 · 소품: 무엇이 보이는지, 얼마나 흐린지
- 조명: 빛의 방향 · 색 · 세기
- 카메라: 렌즈(mm) · 높이 · 각도
- 색감: 기획서 7번 대표 색과 어울리게
- 넣지 말 것: 글자 · 로고 · 간판 글씨 · 사람 얼굴 클로즈업, 기획서 8번
마지막에 이 설계를 영어 이미지 요청문으로 바꿔 코드 상자에 써 줘.
② 만들기 요청 (이미지 만들기 켠 상태)
대표 이미지 설계표대로 이미지를 만들어 줘. 글자는 넣지 마.
② 대신 · 내 상품 사진이 있을 때 (사진을 먼저 올리고)
올린 사진의 주인공은 모양과 색을 그대로 두고, 대표 이미지 설계표대로 배경 · 조명 · 구도만 바꿔서 가로 16:9 광고 사진으로 만들어 줘. 글자는 넣지 마.
이럴 땐설계표의 한 칸만 바꿔요
밋밋해요"조명 칸을 '왼쪽 위에서 들어오는 따뜻한 빛, 그림자 진하게'로 바꿔서 다시"
주인공이 작아요"구도 칸을 '주인공이 화면의 60%'로 바꿔서 다시"
글자 넣을 자리가 없어요"구도 칸을 '주인공 오른쪽, 왼쪽 절반은 비움'으로 바꿔서 다시"
AI 티가 나요"카메라 칸을 '50mm, 눈높이, 자연스러운 흐림'으로 바꿔서 다시"

썸네일 나노바나나

대표 이미지 위에 글자를 얹어요. 글자 크기 · 위치 · 색을 설계표로 먼저 정하면 또렷하고 임팩트 있게 나와요.

① 설계 요청 · 썸네일
위 광고 기획서와 방금 만든 대표 이미지를 분석해서 「썸네일 설계」를 표로 구조화해 줘. 아직 만들지 마.
항목:
- 스타일: 기획서 7번의 썸네일 스타일
- 큰 제목: 기획서 6번 그대로, 정확한 글자
- 작은 문구: 기획서 6번 그대로, 정확한 글자 (없어도 됨)
- 배지: 이벤트 문구가 있으면 배지에 넣을 2~6자
- 글자 위치: 이미지의 빈자리 중 어디
- 글자 크기: 큰 제목은 화면 높이의 몇 % (30% 이상), 작은 문구는 몇 %
- 글자 느낌 · 굵기: 기획서 7번 글자 느낌
- 글자색과 뒤 배경판 · 테두리: 사진 위에서 확실히 읽히게
- 강조색: 기획서 7번 대표 색 중 1개
- 휴대폰 목록의 작은 썸네일에서도 읽히는지 점검 결과
② 만들기 요청 (이미지 만들기 켠 상태)
썸네일 설계표대로, 방금 만든 대표 이미지에 글자를 넣어 줘. 글자는 설계표의 문구만, 사진 속 주인공은 그대로.
이럴 땐설계표의 한 칸만 바꿔요
글자가 안 보여요"배경판 칸을 '대표 색 판, 글자는 흰색'으로 바꿔서 다시"
임팩트가 없어요"글자 크기 칸을 '큰 제목 화면 높이의 40%, 아주 굵게'로 바꿔서 다시"
글자가 틀렸어요"큰 제목을 '[정확한 글자]' 그대로 다시. 다른 글자는 넣지 마"
정신없어요"작은 문구와 배지 칸을 비우고 큰 제목만"
인스타 피드용 정사각형도 필요할 때
같은 썸네일 설계로 1:1 정사각형도 만들어 줘. 글자는 그대로.

8초 광고 영상 Flow · 이미지 → 영상

대표 이미지를 첫 장면으로 넣으면 내 상품 그대로 움직여요. 움직임도 초 단위 설계표로 먼저 정해요.

① 설계 요청 · 영상 (제미나이)
위 광고 기획서와 대표 이미지를 분석해서 「8초 영상 설계」를 표로 구조화해 줘.
항목:
- 0~2초 / 2~4초 / 4~6초 / 6~8초: 각각 화면에 보이는 것과 움직임
- 카메라 움직임: 하나만 (천천히 다가가기, 옆으로 흐르기 등)
- 장면 속 작은 움직임: 1~2개 (김이 오름, 빛이 지나감, 천·잎이 흔들림 등)
- 빛의 변화
- 그대로 지킬 것: 주인공의 모양 · 색 · 위치
- 하지 말 것: 새 물건 · 사람 · 글자 추가, 장면 전환
마지막에 Flow 「프레임으로 동영상」에 붙일 영어 요청문을 코드 상자에 써 줘.
  1. labs.google/flow 접속 → 같은 구글 계정 → 새 프로젝트
  2. 프레임으로 동영상 → 첫 장면(시작 프레임)에 2단계 대표 이미지 올리기
  3. 제미나이가 써 준 영어 요청문을 복사해 붙여 넣기
  4. 화면 비율 가로(16:9), 모델 빠른 모델(Fast) → 만들기 → 2~3분 기다리기 → 다운로드

썸네일(글자 있는 것)은 넣지 마세요. 글자가 움직이면서 깨집니다. 꼭 글자 없는 대표 이미지를 넣어요.

이럴 땐제미나이에게 설계표 한 칸만 바꿔 달라고 하고, 새 영어 요청문으로 다시
너무 많이 움직여요"카메라 움직임 칸을 '아주 천천히 조금만'으로"
상품 모양이 변해요"그대로 지킬 것 칸에 '첫 장면과 똑같은 모양·색'을 더 강하게"
심심해요"장면 속 작은 움직임 칸에 하나 더"
쇼츠·릴스용Flow에서 비율만 세로(9:16)로 바꿔 한 편 더

영상이 만들어지는 동안 쉬는 시간입니다. 20명이 동시에 만들어서 조금 늦을 수 있어요.

① 눈누에서 글꼴 하나 고르기

  3. 「웹폰트로 사용」 코드(@font-face {…})를 통째로 복사해 메모장에 붙여 두기

② 설계표 받기

같은 채팅에 붙여 넣어요. 참고하고 싶은 움직임이 있으면 자료 폴더 「추천모션」 영상(01 네온 간판 · 02 종이 오리기 · 03 전광판 · 04 잡지 표지 · 05 굵은 문구)을 먼저 올리세요.

설계 요청 · 모션그래픽
위 광고 기획서를 분석해서 「10초 모션그래픽 설계」를 표로 구조화해 줘. 아직 만들지 마.
(참고 영상을 올렸다면 그 움직임을 분석해서 반영해 줘.)
항목:
- 장면표: 0~1초 / 1~3초 / 3~7초 / 7~10초 — 각각 화면에 보이는 것 · 움직임 · 글자 · 배경색
  (0~1초는 배경만, 1~3초 가게 이름 등장, 3~7초 메뉴·서비스 3개, 7~10초 이벤트 문구와 연락처)
- 주인공 그림: 기획서 4번 주인공을 도형과 선으로 어떻게 그릴지 (모양 · 색 · 크기)
- 글자: 기획서 6번 문구 그대로, 정확한 글자
- 색: 기획서 7번 대표 색 3개를 어디에 쓰는지
- 큰 효과: 딱 1개, 언제 무엇을
- 빠르기 느낌: 통통 / 부드럽게 / 힘 있게 / 차분하게 중 하나
- 녹화 규칙: 가로 16:9, 끝나면 마지막 화면에서 멈춤, 「다시 보기」 버튼은 오른쪽 아래 구석에 작게

③ 캔버스로 만들기

설계표를 읽고 고칠 곳은 한 가지씩 고친 뒤, 입력창 아래 캔버스를 켜고 붙여 넣어요.

만들기 요청 (캔버스 켠 상태)
모션그래픽 설계표대로 캔버스에 HTML 파일 하나로 만들어 줘.
- 사진 대신 도형 · 선 · 글자로 그리기
- 글꼴은 아래 눈누 웹폰트 코드를 그대로 넣어서 모든 글자에 쓰기
- 보여 주기 전에 글자가 잘리거나 겹치는 곳이 없는지 스스로 확인하기
[눈누 「웹폰트로 사용」 코드 붙여 넣기]
만든 뒤 이럴 땐설계표의 한 칸만 바꿔요
너무 빨라요"빠르기 칸을 '부드럽게'로, 장면마다 1초씩 더 멈추게"
밋밋해요"주인공 그림 칸을 '화면 높이의 절반 크기'로"
정신없어요"3~7초 장면에서 장식은 빼고 카드 3장만"
글자가 이상해요"글꼴을 아까 준 눈누 코드로 다시 적용"
장면 하나가 별로예요"7~10초 장면만 다시 설계해서 보기 3개로 보여 줘"

캔버스 버튼이 안 보이면 새 채팅에서 캔버스를 켜고, 1단계 기획서와 모션그래픽 설계표를 먼저 붙여 넣은 뒤 만들기 요청을 붙여 넣으세요.

쇼츠·릴스용 세로도 필요할 때
같은 설계표로 세로 9:16 버전도 만들어 줘.

④ 영상 파일로 저장하기 (화면 녹화)

  1. 캔버스 미리 보기를 전체 화면으로
  2. Win + Shift + R → 미리 보기 영역을 끌어서 지정 → 녹화 시작
  3. 「다시 보기」 누르기 → 10초 뒤 정지 → 저장

막혔을 때 — 완성 예시 파일로 바로

자료 폴더의 모션예시_빵집.html(상품을 보여 주는 가게) 또는 모션예시_공방.html(과정을 알리는 가게)을 같은 채팅에 올리고:

완성 예시 → 우리 가게로
이 파일에서 맨 위 SHOP 부분만 위 광고 기획서 6번 문구로 바꾸고, 그림도 우리 주인공에 맞게 바꿔서 캔버스에 보여 줘.
나머지 코드는 그대로 두고, 가로 16:9로, 글꼴은 아까 쓴 눈누 웹폰트 코드로.
